# Python Version and Time Docker Application

A simple Dockerized Python application that displays:

- Current Python Version
- Current Date and Time

## Prerequisites

- Docker installed

## Build Image

```bash
docker build -t python-version-time .


## Run image

docker run python-version-time

## Sample Output

Python Version: 3.12.13 (main, Jun 24 2026, 02:08:01) [GCC 14.2.0]
Current Date and Time: 2026-06-24 19:07:26.351844
